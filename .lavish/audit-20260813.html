Critical

C1

February rejected in non-leap years

src/cli/schema.ts:56-59 — the days-in-month superRefine seeds Date.UTC(2000, …) (a leap year → 29 Feb) then calls setUTCFullYear(year). On a non-leap year the 29th rolls to 1 Mar, so daysInMonth === 1.

lumen chart --year 2001 --month 2 --day 2 → “invalid day 2 for month 2 (max 1)”

High

H1

Invalid timezone error is dead code

src/cli/intake.ts:298-314 — the RangeError branch that should emit “Invalid timezone” never fires: toUT throws a plain Error (Unknown IANA time zone: …). Users get a generic “Birth resolution failed” with the raw dependency message, and the suggestion is lost.

H2

draconic + extensions mix coordinate systems

src/core/chart-engine.ts:56-66 — the draconic shift runs before applyExtensions, so eclipse/lot houses are computed against shifted cusps but tropical longitudes from a fresh ephemeris.chartAt. Verified: tropical solar-eclipse house 5, draconic house 3.

Medium

M1

houseOf hides missing cusps

zodiac.ts:59,73 — return 1 when cusps are missing or shorter than 12. Every extension then reports house 1 silently. Test fixtures (cusps: [0,30,60]) pass by accident.

M2

formatEclipse throws bare Error

extensions.ts:84 — throw new Error("Sun position unavailable…") breaks the ADR-0001 contract: everything crossing the seam must be an AxiError.

AXI compliance

A1 — JSON, not TOON

output.ts emits plain JSON. AXI §1 recommends TOON (~40% fewer tokens). ADR-0002 chose JSON for token efficiency — TOON serves that goal better; worth reopening.

A2 — no minimal schema / --fields

output.ts:99-116 always emits 10 fields × ~15 bodies. AXI §2/§3: default minimal + a --fields flag.

A3 — dependency error leaks

intake.ts:310 wraps err.message verbatim (same root cause as H1). AXI §6: translate, never leak the dependency.

Already compliant: --version fast-path (tryFastPath + leaf version.ts), structured AxiError on stdout, fail-loud unknown flags, idempotent setup hooks, summary aggregates.

Recommendation

Fix in this order — C1 (one-line schema bug, blocks real births), then H1 + M2 (error contract), then H2 (coordinate mismatch), then M1. AXI items A1–A3 are a separate standards pass.
